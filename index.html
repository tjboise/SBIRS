How to review (click to collapse)

The ground truth (GT) answers were generated automatically from human pixel labels (the "Human element / Human rust" panels), using fixed question templates. An answer can therefore be wrong because (1) the human label is wrong, or (2) the answer does not match the question.

One image per page. For each question, check that the GT answer overlay really shows what the question asks for, using the original photo and the human labels. Mark Correct / Wrong / Unsure (add a comment if wrong). Answers are saved automatically; when all questions of the image are marked, go to the next image. At the end use Export results and send the file back.

Keyboard: ← / → switch image. "Most" = element with the largest rust area inside it; elements under 200 px are ignored by the generator.
