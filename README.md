# SBIRS Ground-Truth Review

Review page for the auto-generated ground truth (train / val / test) of the BridgeGPT reasoning-segmentation dataset.

**Open the review page: https://tjboise.github.io/SBIRS/**

## How to review
- One image per page: original photo, human element labels, human rust labels, then the questions with their GT answer overlay.
- For each question mark **Correct / Wrong / Unsure** (add a comment if wrong). Progress is saved in your browser.
- When finished, enter your name at the top, click **Export results**, and send the downloaded JSON/CSV file back.
